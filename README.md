# Bucharest exhibitions project

The current usable files are in [`outputs/`](outputs/README.md).

Start with:

- `outputs/bucharest-exhibitions-editor.html` — current editor
- `outputs/bucharest-exhibitions-project-current.json` — current project backup
- `outputs/bucharest-map-implementation.md` — current map documentation

Older presentation exports are stored under `outputs/archive/previous-exports/`. Files under `work/` are historical development materials, not current deliverables.
